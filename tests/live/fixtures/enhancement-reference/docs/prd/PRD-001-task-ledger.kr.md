# PRD-001: Task Ledger

| 항목 | 값    |
| ---- | ----- |
| 버전 | 1.1.0 |

## 소개

Task Ledger는 작업 목록을 관리하고 보고하는 작은 JavaScript 라이브러리입니다.
애플리케이션이 목록을 넘기면 새 목록을 돌려받으므로, 라이브러리는 자체 상태나
저장소가 필요하지 않습니다.

## 기능 요구사항

### FR-001: 작업 추적 (Track tasks)

- **설명**: 제목과 선택적 마감일로 작업을 추가하고, 작업을 완료로 표시합니다.
- **우선순위**: P0
- Task title limit: 120 characters

### FR-002: 진행 상황 보고 (Report progress)

- **설명**: 목록의 전체, 완료, 미완료 작업 수를 숫자와 한 줄 문장으로 보고합니다.
- **우선순위**: P1

### FR-003: 완료 작업 보관 (Archive completed tasks)

- **설명**: 완료된 작업을 보관함으로 옮겨 활성 목록에 미완료 작업만 남깁니다.
- **우선순위**: P2

### FR-004: 기한 초과 작업 보고 (Report overdue tasks) [신규]

- **설명**: 마감일이 지정한 날보다 이전인 미완료 작업을, 마감일이 이른 순서와
  낮은 식별자 순서로 나열합니다.
- **우선순위**: P1
- **추가일**: 2026-11-01
- **변경 사유**: 요청된 개선 사항이며 FR-002의 보고 기능을 확장합니다.

## 비기능 요구사항

라이브러리는 런타임 의존성이 없으며 Node.js 22 이상에서 실행됩니다.
