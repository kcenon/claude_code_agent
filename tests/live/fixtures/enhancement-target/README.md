# Task Ledger

Target repository of the AD-SDLC Enhancement live acceptance scenarios. It is
pushed to a disposable GitHub repository before each live run.

- `src/tasks.mjs`: the task store.
- `src/report.mjs`: progress reporting.
- `docs/`: the product, requirements, and design documents.
- `test/`: the repository's required tests (`npm test`). They must not be
  modified.
